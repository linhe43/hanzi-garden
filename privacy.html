识字小花园 · 隐私政策 / Privacy Policy

更新日期 / Last updated: 2026-09-24

中文

识字小花园不收集、不上传、不出售任何个人信息。本应用没有账号系统，也不包含广告或第三方统计。

孩子的学习进度（星星数量、每个字的熟练程度）只保存在当前设备的浏览器本地存储中，不会发送到任何服务器。卸载应用或清除浏览器数据会删除这些进度。

朗读功能使用设备操作系统自带的语音合成。界面字体从 Google Fonts 加载，加载时 Google 可能会收到设备的 IP 地址等标准网络请求信息。

如有问题，请通过本项目的 GitHub 页面联系开发者。

English

Hanzi Garden does not collect, upload, or sell any personal information. The app has no accounts, no advertising, and no third-party analytics.

Learning progress (stars and per-character mastery) is stored only in the browser's local storage on the device and is never sent to a server. Uninstalling the app or clearing browser data removes it.

Read-aloud uses the operating system's built-in speech synthesis. Interface fonts are loaded from Google Fonts, which may receive standard request information such as the device's IP address.

For questions, please contact the developer through this project's GitHub page.
