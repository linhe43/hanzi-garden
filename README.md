# 识字小花园（Hanzi Garden）设计与开发总结

一个给学龄前 / 低年级孩子用的汉字识字 app。以「田字格」和「小花园」为视觉主题，通过多种小游戏 + 间隔复习，让孩子每天花 15 分钟左右稳定地认字。

- 独立版本（GitHub Pages）：https://linhe43.github.io/hanzi-garden/
- 源码仓库：https://github.com/linhe43/hanzi-garden

---

## 1. 目标与约束

| 维度 | 决定 |
|---|---|
| 使用者 | 自家孩子，可能还不认识拼音，注意力时间短 |
| 平台 | Windows 10/11（鼠标或触摸屏），后续扩展到 iPhone / iPad |
| 核心诉求 | 分阶段学习（先 100 个常用字）；学习过程要有趣，孩子愿意持续学；通过反复出现来巩固记忆 |
| 单次时长 | 大约 15 分钟，不宜过长 |

---

## 2. 内容设计

### 2.1 分阶段、分关卡

- **第一阶段：100 个字，分 10 关，每关 10 个字，按主题分组**：数一数、大自然、我的身体、动物朋友、大小方向、我的家、天气和植物、生活用品、动起来、颜色和时间。
- 选字时优先选**能用图画表示的具体字**（日、山、马、手……）。孩子不用靠拼音，看图就能建立字和意思的联系。
- 数字用对应个数的草莓 emoji 表示（🍓🍓🍓 = 三），顺便练习数数。

### 2.2 每个字的数据

```json
["木", "mù", "木头", "🪵"]
```

依次是：字、带声调的拼音、一个常用词、配图 emoji。

### 2.3 同音字处理

木 / 目、十 / 石、一 / 衣 这类同音字，单独读一个字时听不出区别，所以**读音一律用「字 + 词」的形式**：「木，木头的木」「找一找，木头的木」。

出选择题时，干扰项会排除和正确答案读音相同（不计声调）或配图相同的字，避免出现两个都「对」的选项。

### 2.4 可扩展

所有中文内容（字表、界面文字、表扬语、花园植物）都放在 HTML 里的一个 JSON 数据块中。要加第二阶段，只需在 `stages` 里追加一组，不用改代码。

## 3. 学习方法（玩法）

每关有 5 种玩法，首页还有一个「今日练习」。

| 玩法 | 做法 | 训练什么 |
|---|---|---|
| 📖 学新字 | 大田字格显示字，同时显示配图、拼音和词，自动朗读；可以「描一描」，用手指或鼠标描红 | 初次认识字形、字音、字义 |
| 👂 听音找字 | 听读音，从 4 个字里选出正确的 | 音 → 形 |
| 🖼️ 看图找字 | 看图，从 4 个字里选出正确的 | 义 → 形 |
| 🃏 翻牌配对 | 字卡和图卡配成对 | 形 ↔ 义，外加记忆力 |
| 🌷 浇花开花 | 花坛里有 8 棵插着字牌的小芽，听读音后给对的那棵浇水，它就会开花 | 音 → 形，操作简单，没有时间压力 |
| ☀️ 今日练习 | 系统自动挑出到期要复习的字，复习量不够时补 2–3 个新字；先学新字，再用听音 / 看图混合出题 | 每天只需点这一个按钮 |

### 迭代记录

- **打气球 → 浇花开花**：打气球时气球在飘动，孩子点不准，挫败感强。改成位置固定的花坛，和「小花园」主题也更一致。已经开花的花可以随便点，只会读出字，不算错。
- **翻牌配对加了「先看后翻」**：纯靠运气翻牌，碰到一对的概率太低，玩起来无聊。改成：
  - 每轮开始时所有牌正面朝上展示几秒（4 秒 / 6 秒），然后翻回去，靠记忆去找；
  - 分两轮，先 4 对再 6 对，两轮正好覆盖这一关的 10 个字；
  - 每轮有 2 次「🔍 偷看」，按一下全部牌翻开 1.5 秒，防止孩子卡住。

## 4. 记忆机制：间隔复习

每个字记录一个熟练等级（0–5）、下次到期时间、是否已学过、答对次数、答错次数。

| 等级 | 升到这一级后，隔多久再复习 |
|---|---|
| 0 | 马上 |
| 1 | 4 小时 |
| 2 | 1 天 |
| 3 | 3 天 |
| 4 | 7 天 |
| 5 | 16 天 |

规则：

- **答对**：只有在这个字已经到期时才升一级。两次复习之间反复玩，不会跳过间隔，保证复习真的是「隔开」的。
- **答错**：降两级，并立即到期。同一局里，过两题后再考一次。
- **连错两次**：正确答案开始发光提示，不让孩子一直卡住。
- **解锁下一关**：上一关有 8 个字至少答对过一次。既有门槛，又不会卡太久。

「字宝箱」里 100 个字按熟练度着色：浅绿 = 刚认识，绿 = 有印象，深绿 = 记牢了，金色 = 超熟练。还没学过的字显示成淡灰色。

## 5. 激励设计

- **星星**：答对就得一颗（第一次就答对才算）。
- **小花园**：每攒 10 颗星星，首页的花园里就长出一棵植物或一只小动物，给孩子一个长期积累的目标。
- **反馈全部用动画，不用文字**。孩子还不太识字，「太棒了」这种文字反馈对他意义不大。
  - 答对：字跳一下变绿，四周炸出星星、彩带、彩虹，一颗大星星沿弧线飞进右上角的计数，计数弹一下。
  - 答错：字摇一摇、变淡，冒出一个捂眼小猴 / 偷笑脸 / 小乌龟，晃一晃飘走，下面喷出几朵小烟雾；语音说「这是××的×」，然后重读题目。
- **音效**：用 Web Audio 实时合成，答对是上行三音，答错是低音。不依赖任何音频文件。

## 6. 使用时长控制

- 每次默认 **15 分钟**；家长可以改成 10 / 15 / 20 / 30 分钟或不限时。
- 只在页面可见时计时；离开超过 30 分钟再回来，算新的一次。计时状态存在本地，刷新页面也不会清零。
- **时间到了不打断正在玩的这一局**，等这局结束后进入「休息页」：「今天学得真棒！眼睛累啦，休息一下，明天再来吧」。
- 休息页上家长按住按钮 2 秒，可以再玩 10 分钟。

## 7. 交互与视觉

- **田字格**是贯穿全局的视觉元素：标题、选项、字宝箱、翻牌都用它。字体优先用 Windows 自带的楷体（KaiTi），和课本字形一致。
- **大按钮、立体按压感**，适合手指点击。关闭双击缩放（`touch-action: manipulation`）；描红画布用 `touch-action: none`，防止描字时页面跟着滚动。
- **家长入口**要按住 2 秒才能打开，防止孩子误触。里面可以调语速、选声音、改时长、解锁全部关卡、清空进度（清空需要连按两次确认）。
- **自适应布局**：宽屏和手机竖屏两套布局；支持浅色和深色主题；系统开启「减少动画」时自动关闭飞行动画。
- **emoji 渲染**：从 Google Fonts 加载 Noto Color Emoji，保证 Win10、Win11、iOS 上显示一致。配图大小按 emoji 的实际个数（字素簇数量）自动缩放。

## 8. 语音

- 用浏览器的 `speechSynthesis`，发音引擎是系统自带的：
  - Windows / Edge：优先选「晓晓」等自然语音（需要联网），其次选「慧慧」「瑶瑶」等本地语音。
  - iOS：婷婷。
- 家长可以调语速（默认 0.8）和选择具体的声音。
- **iOS 兼容**：Safari 规定必须由用户操作触发才能出声，所以在孩子第一次点屏幕时，先播一段静音的语音和音频来「解锁」。
- 如果系统没有中文语音，家长设置里会提示如何安装。

## 9. 技术实现

| 方面 | 做法 |
|---|---|
| 形态 | 单个自包含的 HTML 文件，原生 JS + CSS，没有框架和构建步骤 |
| 内容与代码分离 | 所有中文都在 `<script type="application/json">` 数据块里；代码、注释、变量名全部英文 |
| 路由 | 简单的屏幕切换函数 `show(screen, ...args)`；每个屏幕注册自己的清理函数，负责清掉定时器、动画帧和监听器 |
| 进度存储 | 默认存 `localStorage`；在 claude.ai 里运行时，额外同步到用户私有的数据库文档，实现多设备同步 |
| 动画 | CSS 关键帧（跳、摇、开花、翻牌）+ Web Animations API（粒子、飞星） |
| 离线 | Service Worker：页面网络优先，其他资源缓存优先；字体首次使用后缓存 |
| 测试 | 用 Playwright 无头浏览器跑宽屏和手机两种尺寸，走通各个玩法并截图检查 |

## 10. 部署与发布路线

1. **claude.ai 发布版**：最快能用，进度跨设备同步，但需要登录 Claude。
2. **本地文件**：解压后用 `msedge --app=file:///C:/hanzi-garden/index.html` 建一个桌面快捷方式，打开后是没有地址栏的独立窗口，无需登录。
3. **PWA + GitHub Pages（当前主线）**：
   - 仓库包含 `index.html`、`manifest.webmanifest`、`sw.js`、图标、`privacy.html`、`screenshots/`；
   - Windows 上用 Edge「将此站点作为应用安装」；iPhone / iPad 上用 Safari「添加到主屏幕」。
4. **微软商店**：
   - 从 storedeveloper.microsoft.com 注册个人开发者账号（免费，需要证件 + 自拍验证）；
   - 在 Partner Center 预留 app 名字，**必须和 manifest 里的 `name` 完全一致**；
   - 用 pwabuilder.com 生成 .msixbundle 和 .classic.appxbundle 两个包，提交审核。
   - 商店版本质上是 Edge 加载 GitHub Pages 的网址，以后更新内容只要改网站，不用重新提交商店。
5. **浏览器扩展**：评估过，但没有采用。主要好处是能用 `chrome.storage.sync` 在两台电脑间同步进度，但它不支持 iPhone，而且 MV3 需要把内联脚本拆出来、字体也要打包进扩展。

**更新网站时的约定**：改完 `index.html` 后，同时把 `sw.js` 里的 `CACHE` 版本号加一（例如 `hanzi-garden-v1` → `v2`）。
